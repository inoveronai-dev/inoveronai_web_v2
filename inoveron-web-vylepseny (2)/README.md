# Inoveron AI – web pre Vercel

Hotový Next.js projekt pripravený na nasadenie vo Verceli.

## Nasadenie

1. Rozbaľte ZIP súbor.
2. Nahrajte priečinok do GitHub repozitára alebo ho importujte priamo vo Verceli.
3. Vercel automaticky rozpozná Next.js projekt.
4. Build command ponechajte `next build` a potvrďte nasadenie.

Nie sú potrebné žiadne API kľúče ani premenné prostredia.

## Lokálne spustenie

```bash
pnpm install
pnpm dev
```
